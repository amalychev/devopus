| [P-7](../../prototypes/p7-sleep-wake/README.md) | Усыпление и пробуждение < 10 с | ✅ 16/16; 0,11–0,24 с + загрузка приложения; 0 потерянных запросов | Здоровье фичи объявляет агент; закреплённые IP; `init: true` |
| [P-8](../../prototypes/p8-compose-import/README.md) | Импорт `docker-compose.yml` | ✅ 5/5 реальных продуктов без правок, 20/20 экспортируются обратно | 9 изменений в спецификации `workspace.yaml`; гибридный режим — вопрос для интервью |
