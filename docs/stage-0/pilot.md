# Пилот MVP

Пилот начинается, когда MVP (этап 1) готов. На этапе 0 команда только подтверждает намерение ([loi.md](loi.md)).

## Что получает команда

- Агент Devopus для macOS и Linux, бесплатно на время пилота и 6 месяцев после.
- Перевод их compose-проекта в `workspace.yaml` вместе с нами: делаем вместе на первом созвоне.
- Окружение на каждую ветку и каждого AI-агента: свой адрес, свои контейнеры, клон базы за секунды, усыпление неактивных.
- Прямой канал с разработчиками Devopus: ответ в течение рабочего дня.
- Влияние на roadmap: их запросы идут первыми.

## Что нужно от команды

| | |
|---|---|
| Кто | 2–5 разработчиков, один ответственный за обратную связь |
| Срок | 4 недели |
| Окружение | macOS 13+ или Linux; Docker Desktop (OrbStack и Colima — по договорённости); Postgres или MySQL |
| Проект | Продукт с ≥ 2 модулями, запускаемый в Docker (compose или описуемый стек) |
| Время | 1 час на старт, 30 минут в неделю на созвон, 15 минут на итоговую анкету |
| Телеметрия | Обезличенная телеметрия агента включена (без путей, кода и данных) |

## Неделя за неделей

| Неделя | Что происходит | Что меряем |
|---|---|---|
| 0 | Созвон: установка, импорт compose, первое базовое окружение | Время от установки до первой открытой страницы (цель < 15 мин) |
| 1 | Каждый участник создаёт фичи для своих задач | Число фич, ошибки создания |
| 2 | Подключаем AI-агентов (если используют), параллельные ветки | Фичи на человека в неделю, одновременно работающие фичи |
| 3 | Обычная работа | Ежедневное использование |
| 4 | Итоговое интервью и анкета | NPS, готовность платить, что мешало |

## Критерии успеха пилота

- Время до первой открытой страницы < 15 минут хотя бы у одного нового участника.
- Ежедневное использование хотя бы двумя участниками на 3-й и 4-й неделе — это и есть критерий перехода к этапу 2: «3 пилотные команды пользуются каждый день».
- Ни одного случая потери незакоммиченного кода или порчи данных одной фичи другой.
- Ответ «да» или «да, если…» на вопрос о покупке тарифа Team.

## Когда пилот считается неуспешным

- Через 2 недели никто не создаёт фичи сам, без напоминаний.
- Стек команды не поднимается без нашей ручной работы больше одного раза.
