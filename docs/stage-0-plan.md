# План этапа 0 — Валидация

**Критерий выхода:** 5 команд готовы к пилоту + закрыты технические вопросы, блокирующие MVP.

## A. Продуктовая валидация

| # | Задача | Результат |
|---|---|---|
| V-1 | 20 интервью с командами 5–100 разработчиков (продуктовые, агентства, AI-heavy) | Синтез болей; ответ «онбординг vs параллельные фичи» |
| V-2 | Проверка цены Team $15–25/место | Готовность платить, кто платит (тимлид/CTO) |
| V-3 | Замер текущего онбординга у респондентов | Бейзлайн для метрики time-to-first-page |
| V-4 | Сбор 5 реальных стеков (compose-файлы) для тестов импорта | Корпус эталонных проектов |
| V-5 | Список пилотных команд с LOI | ≥ 5 |

**Гайд интервью (кратко):** как сейчас онбордите; сколько времени; сколько веток держите параллельно; как тестируете ветки с БД; используете ли AI-агентов параллельно; что пробовали (DDEV, Codespaces, скрипты); что мешает; кто бы платил.

## B. Технические прототипы

Каждый прототип — выброшенный код с отчётом (решение → ADR).

| # | Прототип | Вопрос | Критерий успеха |
|---|---|---|---|
| P-1 | CLI: `workspace.yaml` → стек на `*.localhost` с HTTPS | Работает ли базовый путь на mac + linux | 3-модульный проект открывается по HTTPS. **✅ macOS / Docker Desktop, 14.10.2026** — [отчёт](../prototypes/p1-p2/README.md); Linux не проверен |
| P-2 | Изоляция Docker: 2 фичи × одинаковые сервисы | Нет ли утечек между фичами | Тесты изоляции зелёные на Docker Desktop, OrbStack, Colima. **✅ Docker Desktop** (7/7) — [отчёт](../prototypes/p1-p2/README.md); OrbStack и Colima не проверены |
| P-3 | Клон Postgres: золотая копия, `FILE_COPY` + `clone` на APFS/ext4/btrfs | Укладываемся ли в 60 с при 1 ГБ | Таблица времён по ФС |
| P-4 | Клон MySQL: CoW-снапшот volume, инстанс на фичу, mysqldump | Какой путь выбрать | Решение в ADR-0007 |
| P-5 | Contextual Isolation: Envoy + baggage + OTel (PHP/Python/Node) | Главная гипотеза отличия работает | Базовый бэкенд, вызванный из фичи, попадает в форкнутую платёжку; очередь с префиксом |
| P-6 | Порты/DNS: launchd socket activation, setcap, `/etc/resolver`, CoreDNS в контейнерах | Работает ли без `0.0.0.0` и без ручных шагов | `curl`, Node, Python резолвят и доверяют сертификату; IPv6 |
| P-7 | Активность и пробуждение через Envoy | Hold запроса + страница «запускаемся» | Пробуждение < 10 с |
| P-8 | Импорт compose на корпусе V-4 | Покрытие формата | ≥ 4 из 5 проектов импортируются без ручных правок |
