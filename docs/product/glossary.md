# Глоссарий

Термины вложены: **воркспейс → проект → модуль**. Фича и окружение всегда принадлежат проекту. Во всей документации слова используются только в этих значениях.

| Термин | Значение | Пример |
|---|---|---|
| **Воркспейс** (Workspace) | Команда или компания: участники, роли, секреты, биллинг | Acme Inc |
| **Проект** (Project) | Продукт команды целиком, описанный одним файлом `workspace.yaml` | Интернет-магазин `shop` |
| **Модуль** (Module) | Часть проекта со своим репозиторием или папкой и своими контейнерами | фронтенд, бэкенд, платёжка |
| **Сервис** (Service) | Инфраструктурная зависимость без своего кода | MySQL, Redis, Mailpit |
| **Базовое окружение** | Весь проект, запущенный с веток `main`; у каждого устройства одно. Никогда не засыпает | `shop.localhost` |
| **Фича** (Feature) | Задача разработчика: набор форкнутых модулей с одной веткой | PAY-123: фронтенд + платёжка |
| **Окружение** (Environment) | Запущенный экземпляр базового окружения или фичи на конкретном устройстве | PAY-123 на ноутбуке Анны |
| **Форк** | Копия модуля в фиче: worktree + контейнеры + при необходимости клон БД | платёжка в PAY-123 |
| **Агент** | Фоновая программа на устройстве, управляющая Docker, git и прокси | `devopus-agent` |
| **Устройство** (Device) | Машина с агентом, привязанная к участнику или к воркспейсу | ноутбук, VPS команды |
| **AI-агент** | Внешний кодинг-ассистент, работающий с фичами через MCP | Claude Code, Codex |

## Дополнительные термины (введены в технических документах)

| Термин | Значение |
|---|---|
| **Золотая копия** | Копия базовой БД, к которой никто не подключается; источник клонов для фич. Пересоздаётся после миграций `main` |
| **Simple Isolation** | Режим, где фича получает свои контейнеры для изменённых модулей *и зависимых сервисов*; адреса — через ссылки `${{payments.url}}` в env |
| **Contextual Isolation** | Режим, где Envoy маршрутизирует по контексту фичи (W3C Baggage), базовые модули общие |
| **Контекст фичи** | Пара `feature=<slug>` в заголовке `baggage`; выставляется только прокси на входной границе |
| **Желаемое состояние** (DesiredState) | Что должно быть запущено на устройстве; хранится на сервере, версионируется ревизией |
| **Фактическое состояние** | Что реально запущено; агент отправляет в `StatusReport` |
| **Расхождение** (drift) | Разница между желаемым и фактическим или между устройствами команды |
| **Override** | Явное личное переопределение разработчика из разрешённого списка (`xdebug`, `ports`) |
| **Превью-ссылка** (PreviewLink) | Публичный URL окружения через Tunnel |
| **ID окружения** | Стабильный идентификатор; используется во всех Docker-ресурсах. Слаг — только в URL |
| **Ресурс общий / собственный** | Пометка в модели фичи: модуль или БД берётся из базового окружения или принадлежит фиче |
