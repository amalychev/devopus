# ADR-0002: Модульный монолит + три деплоя

**Статус:** Accepted

## Контекст
Полноценные микросервисы для маленькой команды дороже в эксплуатации, чем сам продукт.

## Решение
Три деплоя: **Core** (модульный монолит: API gateway, аккаунты, проекты, окружения, секреты, git-интеграция), **Agent gateway** (stateful WebSocket), **Tunnel** (трафик превью). Модули Core изолированы схемами Postgres и внутренними интерфейсами; общаются через NATS. Хостинг на старте — несколько VM (Kamal).

## Последствия
- Любой модуль выносится в отдельный сервис почти механически.
- Падение Tunnel не задевает панель; gateway масштабируется независимо.
- Логи сначала пишутся из Agent gateway напрямую в Loki.
