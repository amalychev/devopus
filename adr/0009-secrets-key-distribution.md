# ADR-0009: Доставка ключа команды на новое устройство

**Статус:** Proposed — **в исходных документах не описано**

## Контекст
Секреты зашифрованы E2E ключом команды (X25519). Новое устройство должно получить ключ, не раскрывая его серверу, иначе онбординг < 15 мин не достижим.

## Варианты
A. Онлайн-устройство админа автоматически оборачивает ключ для нового устройства после одобрения инвайта.
B. Общий сервер команды (Device на уровне Workspace) — key custodian.
C. Recovery-ключ: админ вводит его в браузере (WebCrypto) и оборачивает ключ для устройства.

## Рекомендация
A + fallback C. Ротация ключа при отзыве устройства/участника выполняется на клиенте админа.

## Открытые вопросы
- Нужна ли подпись изменений конфига ключом админа (защита от компрометации платформы, угроза T1)?
