# ADR-0011: Privileged helper и запрет 0.0.0.0

**Статус:** Accepted

## Контекст
На macOS с Mojave порт < 1024 без root открывается только на `0.0.0.0`, что делает окружения с данными доступными всей LAN. Также нужны права для DNS (`/etc/resolver`, NRPT) и установки CA.

## Решение
- Агент работает без root. Минимальный helper: launchd-демон (macOS), Windows Service, на Linux — `setcap cap_net_bind_service` на прокси (иначе rootful dockerd, иначе sysctl с согласия).
- Helper открывает `127.0.0.1:80/443` и `[::1]:80/443` и передаёт сокеты через socket activation; принимает только типизированные запросы.
- **Никогда не слушать `0.0.0.0`.**
- Чужие службы не останавливаются без подтверждения; при конфликте — режимы «сосуществование» и fallback (18443).
