# Нефункциональные требования

Целевые значения для первой версии; каждое измеряется телеметрией или нагрузочными тестами **до релиза** соответствующего этапа.

| ID | Требование | Цель | Этап | Как измеряем |
|---|---|---|---|---|
| NFR-1 | Онбординг: от приглашения до открытой страницы | < 15 мин при 100 Мбит/с и готовых образах | 2 (локальная версия — 1) | Событие `invited` → первый запрос к базовому хосту; эталонный проект 3 модуля |
| NFR-2 | Создание фичи с 2 форками | < 60 с, включая клон БД до 1 ГБ | 1 | Бенчмарк в CI на матрице ФС: APFS (OrbStack), ext4 (Docker Desktop), btrfs/XFS (Linux). P-3: клон БД 1 ГБ — 0,4–0,55 с на ext4 (Docker Desktop), 33 мс с reflink; узкое место — диск, а не время. M6 (`TestFeatureData`, `DEVOPUS_TEST_PG_SCALE=68`): фича с Postgres 1 ГБ и MySQL — 9,4 с на Docker Desktop, 9,6 с на OrbStack |
| NFR-3 | Пробуждение спящей фичи | < 10 с | 1 | Время от первого запроса до 200. P-7: 0,11 с (Node), 0,24 с (Python + Postgres); сверх этого — только время загрузки самого приложения |
| NFR-4 | Изменение в панели → начало применения агентом | < 2 с | 2 | p95 от записи в Core до `StatusReport{CREATING}` |
| NFR-5 | Дополнительная задержка локального прокси | < 2 мс на запрос | 1 | p99 Envoy vs прямой запрос к контейнеру |
| NFR-6 | Потребление агента + прокси в простое | < 150 МБ RAM, < 1% CPU | 1 | Профилирование на эталонном проекте с 5 спящими фичами |
| NFR-7 | ОС | macOS 13+ (AS и Intel), Ubuntu 22.04+ / Debian 12+ / Fedora; Windows 11 через WSL2 | 1 / 3 (Windows) | Матрица E2E-тестов |
| NFR-8 | Работа без интернета | Все запущенные окружения и создание фич из локального кэша | 1 | E2E-тест с отключённой сетью (образы и золотая копия в кэше; `git worktree` от локальной ветки) |
| NFR-9 | Доступность панели и Agent gateway | 99,9% в месяц | 2 | Uptime-мониторинг |
| NFR-10 | Масштаб одного инстанса Agent gateway | 10 000 одновременных агентов | 2 | Нагрузочный тест с эмулятором агентов (heartbeat 15 с, reconnect storm) |
| NFR-11 | Изоляция | 0 случаев, когда одна фича меняет контейнеры/volumes/БД другой | 1 | Интеграционные тесты изоляции на каждом runtime |
| NFR-12 | Безопасность сети | Окружения не доступны из LAN | 1 | Тест: порт-скан с другой машины |
| NFR-13 | Детект офлайна устройства | ≤ 45 с (3 пропущенных heartbeat) | 2 | Тест |
| NFR-14 | Совместимость протокола | Две последние мажорные версии агента | 2 | `buf breaking` + тест совместимости |
| NFR-15 | Удаление | Ни одной потери незакоммиченного/незапушенного кода | 1 | Тест: удаление с грязным worktree без подтверждения невозможно |

## Предлагаемые дополнительные NFR (не из источников)

| ID | Требование | Цель |
|---|---|---|
| NFR-16 | Холодный старт агента после перезагрузки | Базовое окружение доступно < 60 с после логина |
| NFR-17 | Восстановление после краша агента посреди операции | Сходимость к желаемому состоянию без ручных действий |
| NFR-18 | Деинсталляция | Не оставляет DNS-правил, CA, helper'ов (тест «чистая машина после uninstall») |
| NFR-19 | Время `devopus doctor` | < 5 с |
